# Artwork, type & source

- Hero and four project scenes: original AI-generated concept artwork produced with OpenAI's built-in image-generation tool for this package. They have a 3D-rendered aesthetic; no Blender source scene or actual app screenshot is claimed. See [generation prompts](design/art-prompts.md) and the optimized inputs in `design/renders/`.
- Composition, typography, vector achievement sculptures, contribution garden and pixel game art: custom source in this package. Achievement sculptures are unofficial and do not reproduce GitHub's badge designs. The game preview is a frame captured from the actual included canvas game.
- **Space Grotesk**: display typography. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/spacegrotesk), [bundled SIL OFL](docs/fonts/spacegrotesk-OFL.txt).
- **Manrope**: supporting typography. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/manrope), [bundled SIL OFL](docs/fonts/manrope-OFL.txt).
- **Silkscreen**: small pixel-game labels. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/silkscreen), [bundled SIL OFL](docs/fonts/silkscreen-OFL.txt).

The licensed font binaries are bundled locally for the game and regeneration. Display text in published SVGs is converted to paths using the actual bundled fonts, with accessible title/description and README alt text. Native Markdown retains GitHub's fonts. No proprietary font files, external font requests, third-party trophy images, emoji sprites or runtime libraries are included.
